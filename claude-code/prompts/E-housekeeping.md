# Workstream E — Recorded debts that cap professionalism or scale

Each of these is already written down in `CLAUDE.md` as a named cost. They are here because a
reviewer, a funder or a security questionnaire will find them.

## E1 — CSP nonces, drop `unsafe-inline`
The CSP carries `script-src 'unsafe-inline'` until the islands get nonces through the Astro
middleware (ADR-0030's recorded cost). Generate a per-response nonce in
`frontend/src/middleware.ts`, thread it to every inline island, remove `unsafe-inline`, and add an
e2e test asserting the header no longer contains it and the islands still work.

## E2 — `HEAD` is 405 on every `/api/v1` route
FastAPI registers GET alone. This breaks CDNs and uptime monitors. Register HEAD (or add a
middleware that answers it from the GET route) and test one route per family.

## E3 — Revisit `Disallow: /`
ADR-0037 blocks all crawlers from the Caddyfile, after two AI crawlers walking the `?release=`
axis — 25M reader pages behind it — pinned the box at 43,068 req/hr against ~48 human ones. Blunt
on purpose while the site is a demo. But a legal-research site nobody can find is not
professional, and the fix is narrower than a blanket block:
- `Allow` the canonical current-release spine (titles, chapters, the 65,938 current sections),
  `Disallow` the `?release=`/`?date=`/`?id=` axis and `/app/diff`;
- `rel=canonical` on every versioned page pointing at its current-release form;
- a real sitemap for the spine only, generated by the load chain;
- keep the Caddy-level rate limit and keep serving `robots.txt` from the host (one Caddy owns it),
  and remember `deploy-on-box.sh` must **force-recreate** the proxy — the single-file bind mount
  binds an inode, so `caddy reload` reloads the pre-checkout file and exits 0.
Amend ADR-0037 rather than replacing it; the measurement in it is the reason for the rate limit
that stays.

## E4 — Vendored API docs update path
2.4 MB of Swagger UI / ReDoc is committed (ADR-0032), so a security fix in either arrives only when
someone bumps `static/apidocs/MANIFEST.json`. Add a scheduled Actions job that checks upstream
versions and opens an issue or a PR.

## E5 — Regenerate the stale verification artifacts
`docs/verification/loadtest.json` predates ADR-0029's limiters, ADR-0026's reader redline and
ADR-0037's `Disallow: /`. Regenerate against the deployed box (B3), and note in the file which
release of the site it measured — a verification artifact with no version is a claim, not evidence.
